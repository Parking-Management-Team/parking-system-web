## 1. Visual Theme & Atmosphere

A controlled, infrastructure-grade interface that feels like a command center for urban mobility. The atmosphere is **clinical precision with warm operational confidence** — like a well-lit traffic control room that also happens to be beautiful.

- **Density:** 4 — "Daily App Balanced" — Generous whitespace on landing, higher density in dashboard
- **Variance:** 7 — "Offset Asymmetric" — Every section breaks the expected grid rhythm
- **Motion:** 6 — "Fluid CSS Spring Physics" — Elements have weight and resistance, not linear snaps

The color story is deliberate: Deep Slate backgrounds evoke urban infrastructure and nighttime city grids. A single Emerald accent cuts through like a green traffic signal — purposeful, trustworthy, unmissable. In light mode, the same Emerald grounds an airy off-white canvas with equal authority.

**Design personality in one sentence:** "The parking system that feels as smart as the city it serves."

## 2. Color Palette & Roles

### Dark Mode (Primary)
- **Deep Slate Canvas** (`#0F172A`) — Primary dark background, the "night city grid" base
- **Midnight Surface** (`#1E293B`) — Card backgrounds, panel fills, elevated containers
- **Abyss Depth** (`#020617`) — Deepest layer: nav bar background, footer, sidebar
- **Whisper Border Dark** (`rgba(148, 163, 184, 0.12)`) — Structural dividers, card outlines, 1px lines
- **Shadow Dark** (`rgba(0, 0, 0, 0.5)`) — Card elevation shadow, tinted to background hue

### Light Mode
- **Off-White Canvas** (`#F8FAFC`) — Primary light background, never pure white
- **Pure Surface** (`#FFFFFF`) — Card and container fill, elevated panels
- **Whisper Border Light** (`rgba(148, 163, 184, 0.25)`) — Structural lines, card borders
- **Shadow Light** (`rgba(15, 23, 42, 0.06)`) — Subtle card elevation

### Typography Colors
- **White Ink** (`#F8FAFC`) — Dark mode primary text
- **Pale Slate** (`#CBD5E1`) — Dark mode secondary text, metadata, captions
- **Charcoal Ink** (`#0F172A`) — Light mode primary text
- **Slate Muted** (`#64748B`) — Light mode secondary text, descriptions

### Single Accent (MAXIMUM 1)
- **Emerald Signal** (`#059669`) — Primary accent: CTAs, active states, focus rings, icon highlights, badge fills. Saturation ~72% — below 80% cap.
- **Emerald Deep** (`#047857`) — Hover/pressed state. Never used as independent color.

**BANNED:** Any purple, violet, indigo, cyan-neon, or multi-accent configurations.

## 3. Typography Rules

### Font Stack
- **Display / Headlines:** `Be Vietnam Pro` — weights 700–800. Track-tight (`letter-spacing: -0.02em` to `-0.04em`). Hierarchy through weight contrast, not just size escalation. Supports full Vietnamese diacritical marks natively.
- **Body / UI:** `Be Vietnam Pro` — weights 400–500. Relaxed line-height (`1.6`–`1.75`). Maximum 65 characters per line. Secondary text in Slate Muted color.
- **Monospace:** `JetBrains Mono` — weights 400–500. Used for: plate numbers, timestamps, fee amounts in high-density contexts, codes.

### Vietnamese Support
- Font subset MUST include `vietnamese` alongside `latin` when loading via next/font
- All diacritical marks must render correctly: ắ ẽ ọ ử ặ ổ ươ ề ẫ
- No fallback to system fonts for Vietnamese text

### Scale Hierarchy
- **Hero Headline:** `clamp(2.5rem, 6vw, 4.5rem)` — 700–800 weight
- **Section Title:** `clamp(1.75rem, 3.5vw, 2.5rem)` — 700 weight
- **Subsection:** `1.25rem`–`1.5rem` — 600 weight
- **Body:** `1rem` (`16px`) — 400 weight — minimum never below `14px`
- **Caption / Meta:** `0.875rem` (`14px`) — 400–500 weight, Slate Muted color

### Banned
- `Inter` — banned, AI default
- `Roboto`, `Open Sans` — generic system fallback
- Any serif font (`Times`, `Georgia`, `Garamond`) — banned in all UI contexts
- `font-size` below `14px` for any readable text

## 4. Component Stylings

### Buttons
- **Primary:** Emerald Signal fill (`#059669`), White text, `border-radius: 0.5rem` (8px — clean, not over-rounded). On hover: `translateY(-1px)`, background deepens to `#047857`. On active: `translateY(0)`, `scale(0.98)`. No outer glow. No shadow on default state.
- **Ghost:** Transparent fill, Emerald Signal border (1px), Emerald Signal text. Hover: thin Emerald fill at `opacity: 0.08`.
- **Outline Neutral:** Transparent fill, Whisper Border border, current text color. For secondary actions.
- **Destructive:** Slate Rose `#E11D48` fill, same interaction pattern as Primary.
- Touch target minimum: 44px height on all variants.

### Cards
- `border-radius: 1rem` (16px) — generously rounded but not pill-shaped
- Background: Midnight Surface in dark, Pure Surface in light
- Border: 1px Whisper Border (use border, not box-shadow outline)
- Box shadow: `0 1px 3px var(--color-shadow)` — subtle, tinted to background hue
- Hover elevation: `0 8px 24px var(--color-shadow)` — lift effect via `translateY(-2px)` + shadow increase
- Cards used ONLY when elevation communicates hierarchy. For data-dense lists: use border-top dividers instead.

### Inputs & Forms
- Label ALWAYS above input — no floating labels
- Border: 1px Whisper Border default, Emerald Signal on focus
- `border-radius: 0.5rem` (8px)
- Focus ring: `outline: 2px solid #059669`, `outline-offset: 2px`
- Error text: Below input, Rose `#E11D48`, `0.875rem`
- Helper text: Below label or below input (never inside)
- Placeholder: Slate Muted `#64748B`

### Badges / Status Indicators
- `border-radius: 9999px` (full pill)
- **AVAILABLE:** Emerald `#059669` background at `opacity: 0.15`, Emerald text
- **OCCUPIED:** Rose `#E11D48` at `opacity: 0.15`, Rose text
- **RESERVED:** Amber `#D97706` at `opacity: 0.15`, Amber text
- **EXPIRED / INACTIVE:** Slate at `opacity: 0.15`, Slate text
- Padding: `0.25rem 0.75rem`, `font-size: 0.75rem`, `font-weight: 600`

### PriceTag Component
- Monospace font (`JetBrains Mono`) for the number
- Currency symbol (₫) in Be Vietnam Pro, smaller size
- Emerald accent for active/featured prices
- Format: `5.000 ₫` (Vietnamese number format with `.` thousands separator)

### Skeleton Loaders
- Shimmer animation: gradient sweep from `#1E293B` to `#334155` to `#1E293B` in dark mode
- Exact same dimensions as the content they replace — never generic rectangular blobs
- Animation: `1.5s` linear infinite

### Loading States
- No circular spinners anywhere
- Skeletal shimmer only, matching layout dimensions precisely

## 5. Layout Principles

**Grid system:** CSS Grid primary. Flexbox only for single-axis alignment. Never `calc()` percentage hacks.

**Max-width container:** `1400px` centered with `clamp(1.5rem, 5vw, 6rem)` horizontal padding.

**Hero Layout:**
- Left-aligned asymmetric — headline and CTA on left column (~60%), visual/stats on right (~40%)
- Centered hero layouts BANNED for this project (variance > 4)
- Headline starts at left edge of container, not centered

**Section spacing:** `clamp(5rem, 10vw, 8rem)` vertical padding between sections

**Feature rows:** 2-column zig-zag layout (text left / visual right, then visual left / text right). The generic "3 equal cards horizontally" layout is banned.

**Full-height sections:** Use `min-h-[100dvh]` — never `h-screen` (iOS Safari viewport jump)

**No overlapping elements:** Every element occupies its own clean spatial zone. No absolute-positioned content stacking on top of other content.

**Pricing section:** 3-tab switcher (not 3 cards side by side). Each tab reveals a distinct layout — asymmetric comparison, not equal columns.

---

## 6. Responsive Rules

- **Mobile-first:** All styles written for < 768px, then expanded via `min-width` breakpoints
- **< 768px:** All multi-column layouts collapse to single column. No exceptions.
- **No horizontal scroll:** Critical failure if any content overflows horizontally on mobile
- **Typography:** All headlines scale via `clamp()`. Body never below `1rem`/`16px`
- **Touch targets:** All interactive elements minimum `44px` × `44px`
- **Navbar:** Desktop horizontal nav collapses to hamburger menu on mobile. Clean slide-in drawer, not full-screen overlay.
- **Spacing:** Section vertical gaps reduce proportionally via `clamp(3rem, 8vw, 6rem)`
- **Language switch:** Visible in both mobile and desktop nav

## 7. Motion & Interaction

**Spring physics defaults:** `stiffness: 100, damping: 20` — premium, weighty feel. Never linear easing.

**Scroll reveal:** All sections and major elements use `IntersectionObserver` + CSS `@keyframes` — fade up (`translateY(24px) → 0`, `opacity: 0 → 1`). Threshold: `0.15`. Stagger delay between children: `80ms`.

**Staggered cascade:** Lists, feature grids, stat counters — never mount instantly. Cascade delay: `0ms, 80ms, 160ms, 240ms...`

**Perpetual micro-interactions:**
- Emerald accent pulse on active status indicators (parking available count)
- Typewriter effect on hero stats counter on viewport enter
- Subtle float animation on hero visual element (`translateY(0px) ↔ translateY(-8px)`, 4s ease-in-out infinite)

**Button feedback:** `translateY(-1px)` on hover, `translateY(0) scale(0.98)` on active — tactile push feel

**Performance rules:**
- Animate ONLY `transform` and `opacity` — never `top`, `left`, `width`, `height`, `background-color` directly
- `will-change: transform` only on actively animating elements, removed after animation ends
- `prefers-reduced-motion` media query MUST be respected — all animations disabled when active
- Grain/noise textures on fixed pseudo-elements only (never on scrolling content)

## 8. Language & Localization

- **Default locale:** Vietnamese (`/vi`)
- **Secondary locale:** English (`/en`)
- All UI text from `messages/*.json` — no hardcoded strings in components
- Language switch in navbar — toggle between VI and EN
- Date format: `DD/MM/YYYY` for VI, `MM/DD/YYYY` for EN
- Currency: Always Vietnamese Dong (₫), format `X.XXX ₫` regardless of locale
- Number format: Vietnamese style (`.` as thousands separator) for all monetary values

## 9. Anti-Patterns (Banned — Absolute)

- No emojis anywhere in the UI
- No `Inter` font — `Be Vietnam Pro` is the only sans-serif
- No generic serif fonts (`Times New Roman`, `Georgia`, `Garamond`) — banned completely
- No pure black (`#000000`) — use `#0F172A` (Slate-900) or `#020617` (Slate-950)
- No neon glow / outer box-shadow glow effects
- No oversaturated accent colors (saturation must stay below 80%)
- No purple, violet, indigo, or magenta as primary/brand colors — ever
- No glassmorphism (`backdrop-filter: blur`) as a design aesthetic
- No custom mouse cursors
- No overlapping elements — clean spatial separation in all zones
- No 3-column equal card layouts for feature sections — use zig-zag or asymmetric grids
- No generic placeholder names ("John Doe", "Acme Corp", "User 123")
- No fake round numbers in stats (`100%`, `50%`, `1000 lượt`) — use specific realistic values
- No AI copywriting clichés: "Elevate", "Seamless", "Unleash", "Next-Gen", "Empower", "Revolutionize"
- No filler UI text: "Scroll to explore", "Swipe down", bouncing chevron arrows
- No broken image links — use `/placeholder.svg` or `picsum.photos` with fixed seeds
- No centered hero sections — always left-aligned asymmetric
- No secondary CTA buttons ("Learn more", "Read more") next to primary CTA in hero
